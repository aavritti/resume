# Aavritti Soni — Resume

A responsive portfolio-style resume page with a downloadable PDF.

- Website: https://aavritti.github.io/resume/
- Repository: https://github.com/aavritti/resume
- PDF resume: [aavritti_soni_resume.pdf](aavritti_soni_resume.pdf)

## Publish with GitHub Pages

1. Upload `index.html`, `aavritti_soni_resume.pdf`, and this README to the repository root on the `main` branch.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for the Pages deployment to finish. GitHub will show the published URL in Pages settings.

The page links to the PDF in the same repository, so keep the PDF filename unchanged or update the link in `index.html` too.
