# Aavritti Soni — Resume

Download the latest resume: [aavritti_soni_resume.pdf](aavritti_soni_resume.pdf)

## Host this on GitHub

1. Create a public repository named `resume` (or another name you prefer).
2. Upload `README.md` and `aavritti_soni_resume.pdf` to the repository root.
3. Commit the files. The PDF will be available at:
   `https://github.com/aavritti/resume/blob/main/aavritti_soni_resume.pdf`

To use a clean web link such as `https://aavritti.github.io/resume/`, enable GitHub Pages for the repository and add an `index.html` page linking to the PDF.
